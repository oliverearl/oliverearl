# 👋 Hey, I’m Ollie

<img align="right" alt="A cute PHP elephant that I drew" height="200" src="https://github.com/oliverearl/oliverearl/assets/14837181/ead3f393-4a1b-4357-9b3a-452bad98b760" />

I'm a senior software engineer from Birmingham, UK, working primarily with **PHP, Laravel, databases and backend systems**.

By day, I'm a Senior Laravel Developer at [Spindogs](https://www.github.com/spindogs). Outside work I contribute to [Three Rings](https://github.com/ThreeRingsCIC) and [Petrobolos](https://www.github.com/petrobolos), dabble in open source, and occasionally see how far I can push PHP before it complains.

## Things I care about

Maintainable software, good tests, open source, retro computing, and finding interesting problems that probably didn't need solving in PHP.
I'm also a former computer science teacher, and I'm particularly interested in technology that serves communities and the public good.

## Elsewhere

I write about software and whatever else has caught my attention at **[oliverearl.co.uk](https://www.oliverearl.co.uk)**.
